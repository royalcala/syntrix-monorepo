# Bienvenidos a Syntrix

Syntrix es un espacio de colaboración descentralizado, diseñado para ser inquebrantable, privado, orgánico y ultra-resiliente.

Esta es la sección oficial de documentación. Aquí encontrarás guías definitivas de funcionamiento y desarrollo.

> [!NOTE]
> Esta sección se encuentra actualmente en desarrollo activo. Si deseas revisar los borradores iniciales de arquitectura y diseño, puedes desplegar el menú **Archivo de Diseño (Drafts)** en la barra lateral.
