# Bienvenidos a Syntrix

Syntrix es un espacio de colaboración descentralizado, diseñado para ser inquebrantable, privado, orgánico y ultra-resiliente.

Esta es la documentación oficial. Aquí encontrarás guías de desarrollo, arquitectura core, referencia de API y la hoja de ruta del producto.
