# Instalación y Setup

Aquí se detallará el proceso definitivo de configuración de Syntrix.

## Requisitos Previos

- Nix / NixOS (con comandos experimentales activados para Flakes)
- Node.js 22+ y pnpm 11+
- Rust y Cargo (para compilar las aplicaciones Tauri del admin y cliente)

> [!NOTE]
> Para consultar los pasos iniciales y el roadmap del proyecto, por favor revisa el **Archivo de Diseño (Drafts)**.
